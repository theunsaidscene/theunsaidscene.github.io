Privacy policy

Effective October 11, 2026. This policy describes The Unsaid Scene Automation, a personal tool operated by the owner of unsaidscene@gmail.com.

Google and YouTube information

The owner authorizes YouTube upload and read-only scopes. The tool uses OAuth credentials to refresh access, reads the authorized channel ID to verify the destination, and, when explicitly enabled, uploads reviewed video files with their metadata. It does not request Gmail access.

Storage and service providers

OAuth client credentials and a refresh token are stored in encrypted GitHub Actions repository secrets. Access tokens are used during workflow runs. GitHub runs the automation; Google processes authorization and YouTube API requests. Drafts are retained as GitHub artifacts for the configured period, currently one day. Code and scripts are stored in a private repository. Future upload-state records will be retained until the owner deletes them. Secrets are not intentionally written to logs.

Use and sharing

Google user data is used only for this channel-management function. It is not sold or used for advertising or AI model training by this application. Access is limited to the owner, authorized repository administrators, and the service providers needed to run the workflow. The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including Limited Use requirements.

Revocation and deletion

The owner can revoke access at Google Account connections, delete GitHub secrets and stored artifacts, and delete uploaded videos through YouTube Studio. Revoking access does not itself delete previously uploaded videos. For assistance contact the email below.

Website visitors

These static pages do not use application analytics, forms, or cookies. If deployed on GitHub Pages, GitHub records visitor IP addresses for security under its own privacy policy.
